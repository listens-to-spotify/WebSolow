Веб-приложение модель Солоу

Курсовая работа по моделированию экономических отношений

Описание проекта

Это веб-приложение для численного моделирования и визуализации модели экономического роста Солоу. Приложение позволит устанавливать начальные условия, изменять параметры в реальном времени и рассматривать различные сценарии экономического развития.

Информация о проекте

Стек технологий (MVP): JavaScript/HTML/CSS (фронтенд), Nginx (сервер)

Дедлайн проекта: 7 июня 2026 года

Ближайшие шаги

  • Разработка архитектуры приложения
  • Создание интерактивного интерфейса
  • Реализация математической модели
  • Настройка визуализации графиков
